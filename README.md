# 📈 Toss Bot 백테스팅 리포트 & 시뮬레이터 (TQQQ vs SOXL)

토스증권 해외주식 자동매매 봇의 **LOC 2분할 매수 + 평단가 대비 10% 지정가 익절 매매 전략**에 대한 백테스팅 시뮬레이터 및 상세 성과 분석 리포트입니다.

---

## 📌 매매 전략 로직 (Trading Strategy)

매일 미국 정규장 시작 전 자동으로 주문을 생성하고 장마감 시점에 체결을 확인합니다.

1. **기준 가격(`base_price`) 산정**:
   - 보유 주수가 있을 때: 현재 **보유 평단가**
   - 보유 주수가 없을 때: **직전 거래일 종가 × 0.95** (5% 할인된 가격)
2. **매수 주문 (LOC - Limit on Close)**:
   - **매수 ①**: `base_price` (평단가 또는 5% 하향가)에 1주 매수
   - **매수 ②**: `전일 종가 × 1.10`에 1주 매수 (상승장 추종 매수)
3. **매도 주문 (DAY LIMIT - 정규장 지정가)**:
   - 보유 수량 전체를 `base_price × 1.10` (+10% 익절가)에 전량 지정가 매도 등록
   - 장중 고가가 익절가에 도달하면 전량 체결되어 사이클 종료 (`qty = 0`)

## 🚨 2022년 대하락장 심층 분석 (핵심 리스크와 교훈)

### 1) SOXL의 666주 1년 5개월 대탈출 드라마
* 2022년 반도체 대폭락 당시 SOXL은 **1년 내내 단 한 번도 +10% 익절선에 닿지 못하고 연속 하락**했습니다.
* 봇은 매일 1~2주씩 물타기를 지속하여 평단가를 $70대에서 **$19.95**까지 낮췄습니다.
* **최대 666주까지 누적되었으며, 필요했던 최대 현금은 $13,289(약 1,820만원)**였습니다.
* 마침내 **2023년 5월 26일**, 엔비디아發 AI 반도체 랠리로 666주 전량을 주당 $21.95에 일괄 매도하여 **단 한 번에 +$1,329.23(+10%)의 수익을 거두며 완벽히 탈출**했습니다.
> ⚠️ **핵심**: 전략 자체는 대하락장에서도 살아남지만, **시드가 1,500만원 이상 준비되지 않았다면 중간에 매수가 끊겨 실패했을 것**입니다.

### 2) TQQQ의 뛰어난 하락장 방어력
* 빅테크 종목들의 지지 덕분에 2022년 베어마켓 랠리(3월, 8월) 동안 **하락장 속에서도 2번이나 전량 익절**에 성공했습니다.
* 2022년 연중 최대 필요 시드는 **$3,067(약 420만원)**에 불과해 심리적 부담과 자금 압박이 현저히 적었습니다.

## 🛠️ 실행 방법 (Usage)

### 1. 환경 준비
```bash
pip install -r requirements.txt
```

### 2. 개별 종목 백테스팅 실행
```bash
# TQQQ 2022년부터 실행
python backtest.py --symbol TQQQ --start 2022-01-01

# SOXL 2026년부터 실행 (익절 목표 10%)
python backtest.py --symbol SOXL --start 2026-01-01 --tp 0.10
```

### 3. 전체 비교 및 JSON 결과 추출
```bash
python compare_all.py
```
실행 시 `results_2022_2026.json` 및 `results_2026.json`에 상세 거래 데이터가 자동 저장됩니다.
