# 📈 Toss Bot 백테스팅 리포트 & 시뮬레이터

토스증권 해외주식 자동매매 봇의 **LOC 2분할 매수 + 목표 익절가 지정가 매도 전략**에 대한 종목별/배수별 백테스팅 비교 리포트입니다.

---

## 📌 매매 전략 로직 (Trading Strategy)

매일 미국 정규장 시작 전 자동으로 주문을 생성하고 장마감 시점에 체결을 확인합니다.

1. **기준 가격(`base_price`) 산정**:
   - 보유 주수가 있을 때: 현재 **보유 평단가**
   - 보유 주수가 없을 때: **직전 거래일 종가 × 0.95** (5% 할인된 가격)
2. **매수 주문 (LOC - Limit on Close)**:
   - **매수 ①**: `base_price` (평단가 또는 5% 하향가)에 1주 매수
   - **매수 ②**: `전일 종가 × 1.10`에 1주 매수 (상승장 추종 매수)
3. **매도 주문 (DAY LIMIT - 정규장 지정가)**:
   - 보유 수량 전체를 `base_price × (1 + 목표익절률)`에 전량 지정가 매도 등록
   - **QQQ / QQQM (1배수)**: **+3.3% 익절**
   - **QLD (2배수)**: **+5.0% 익절**
   - **TQQQ / SOXL (3배수)**: **+10.0% 익절**

## 💡 핵심 분석 및 인사이트

### 1) QQQ vs QQQM (1배수, 3.3% 익절)
* 두 종목은 동일한 나스닥 100 지수를 추종하므로 **익절 횟수(38회)와 수익률(31%)이 완전히 동일**합니다.
* 하지만 **1주 고정 매수 방식** 특성상:
  * QQQ는 주당 단가가 높아 최대 **$86,858 (약 1억 2천만원)**의 시드가 필요합니다.
  * QQQM은 주당 단가가 약 2.4배 낮아 최대 **$35,122 (약 4,800만원)**로 운영이 가능합니다.
  * 👉 **1배수로 안전하게 운용하고 싶다면 QQQ 대신 반드시 QQQM을 추천합니다.**

### 2) QLD (2배수, 5.0% 익절) 의 압도적 가성비
* **48회의 최다 익절**: 5.0% 익절선은 2배 레버리지 특성상 적당한 기술적 반등만 나와도 즉시 도달하여 계좌 회전율이 가장 높습니다.
* **최소 시드 소모**: 2022년 대폭락장에서도 최대 필요 시드가 **$6,509 (약 890만원)**에 불과했습니다.
* **최고의 ROI**: 최대 시드 대비 총 수익률이 **+64.91%**로 전체 종목 중 1위입니다.
* 👉 **1,000만원 미만 소액 시드로 가장 안정적이면서도 빠른 회전율을 원할 때 최적의 선택입니다.**
